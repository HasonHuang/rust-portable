## rust-portable v1.99.1

首个公开版本。下载后解压即可使用，不需要安装 Rust、Visual Studio 或 MinGW。
项目版本号与 Rust 版本号一致。

### 平台

- Windows 10/11 x64

### 工具链

- Rust 1.99.1
- Cargo 1.99.1
- rustup 1.29.2
- MinGW-w64 GCC 16.2.0
- Target: `x86_64-pc-windows-gnu`
- 组件：rustfmt、clippy、rust-analyzer、rust-src

### 资产

- `rust-portable-v1.99.1-windows-x64.zip`
- `SHA256SUMS`

### 安装

1. 解压到不含空格的路径。
2. 运行 `windows\configure-env.bat`。
3. 重新打开终端。
4. 运行 `windows\doctor.bat` 完成自检。

临时使用可以运行 `windows\open-shell.bat`，不修改用户环境变量。

### 已知限制

- Windows 路径不能包含空格。此限制来自 WinLibs MinGW GCC。
- 仅支持 Windows 10/11 x64。
- Linux 支持尚未包含。
- 第三方 crate 仍需要联网下载或提前准备 vendor 目录。

### 第三方组件

Rust、Cargo、rustup 使用 MIT OR Apache-2.0。
MinGW-w64、GCC 和 WinLibs 组件使用各自的许可证。
许可证文本在压缩包的 `shared/licenses/` 中。
版本和下载来源见 `shared/VERSIONS.md`。

GCC 和 MinGW-w64 的源码来源：

- GCC: <https://gcc.gnu.org/git/gcc.git>
- MinGW-w64: <https://github.com/mingw-w64/mingw-w64>
- WinLibs: <https://winlibs.com/>
