# Linux 目录（计划中）

本项目是跨平台便携式 Rust 开发环境。
Windows 工具链已包含。Linux 工具链尚未包含。
此目录为 Linux 支持预留。

Linux 支持加入后，这里计划包含：

- `cargo/`：Cargo 主目录
- `rustup/`：rustup 主目录
- `env.sh`：在当前 shell 中激活环境
- `setup.sh`：写入用户的 shell 配置
- `doctor.sh`：检查工具链和 C 编译器

当前目录只有本说明文件。
Windows 工具链不能在 Linux 上运行。

在 Windows 上，请使用 `../windows/` 中的脚本。
在 Linux 上，请等待 Linux 支持加入。
